Aperture UI redesign — visual mockups

High-fidelity frames for the proposal in docs/superpowers/specs/2026-11-16-aperture-ui-redesign.md. Static mockups only: no app code was changed. Colours, radii and type sizes are the existing Studio tokens from MirpgStudioPalette / MirpgRemoteTheme (dark). Emulator names and IDs are placeholders. Each frame's caption says what changed against today and why; dashed notes name the open question (Q1–Q7) the frame depends on and show the proposed default.

State badge: one word, one shape, one colour

Live Starting Stopped Stopping Copying 42% Problem

Each state has its own glyph (filled dot, arc, ring, square, triangle) so it never relies on colour alone. "Problem" always carries one line of cause.
